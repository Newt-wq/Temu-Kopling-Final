# Temu Kopling

Antarmuka platform mobilitas berbahasa Indonesia, dibangun dengan React, TypeScript, dan Vite.

## Pengembangan

Gunakan Node.js 22.12.0 (`nvm install && nvm use`), kemudian:

```sh
npm ci
npm run dev
```

Validasi: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
Preview build: `npm run preview`.

Repository ini dimulai dari kosong. Aplikasi merupakan demo frontend; tidak terhubung ke
backend, penyedia pembayaran, atau layanan dispatch transportasi.
